# Xinyu Dou — academic website

Source for [Xinyu Dou's personal website](https://cynthia-xinyu.github.io/xinyu-dou-website/), covering research interests and publications.

## Run locally

This is a static website. Open `index.html` in a browser, or serve the folder with any static HTTP server. The navigation also includes `research.html` and `publications.html`.
